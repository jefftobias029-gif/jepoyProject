# Quotation Tool

Single-file web app (Tailwind via CDN) for building and printing quotations,
using Google Sheets as the database and Google Drive for image storage.

Open `index.html` in a browser, or host it on GitHub Pages.

## Connecting Google Sheets

The Apps Script Web App URL is **not** stored in the code. Open the app, go to
**Settings**, paste your URL into "Google Apps Script Web App URL" and click
**Save & Connect**. It is saved only in your own browser.
